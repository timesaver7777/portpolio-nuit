# NUIT LAB (뉘이랩) — 건기식·이너뷰티 고전환 D2C 샘플몰 포트폴리오

스레드(Threads) 자사몰·세일즈 랜딩페이지 외주 수주를 위해 설계된 **고전환 D2C 단일 주력 상품(One-Product Funnel) 샘플 스토어**입니다.

## 브랜드 & 제품 컨셉
- **브랜드**: `NUIT LAB (뉘이랩)`
- **주력 제품**: 리포좀 마그네슘 & 몽모랑시 타트체리 나이트 샷 (1박스 14포 고농축 액상 스틱 앰플)
- **컬러 시스템**: 웜 아이보리(`#FAF8F5`) · 딥 보타니컬 차콜(`#181A18`) · 타트체리 버건디(`#8E2438`)

## 핵심 전환 퍼널(Conversion Funnel) 사양
1. **퍼스트 폴드 바이박스 (First-Fold Buy Box)**
   - 전용 스튜디오 제품·제형·라이프스타일 갤러리 4종 전환
   - `★ 4.9 (1,428건)` 실구매 리뷰 앵커 및 평일 14시 당일출고 실시간 카운트다운
   - 객단가 상승용 번들 선택기 (`1박스 12%↓` / `3박스+4포 증정 BEST 32%↓ 무료배송` / `6박스 45%↓`)
   - **정기구독 추가 10% 할인 실시간 토글** (선택 즉시 전 옵션 단가·절약 금액·1포당 가격 실시간 계산)
2. **시맨틱 웹 설득 섹션**
   - `01` 문제 제기 & 인지질 리포좀 액상 체내 흡수율 비교 시각화
   - `02` 타사(일반 타트체리 주스·정제 알약) 대비 5대 핵심 스펙 비교표
   - `03` 핵심 원료 배합 & 14일 나이트 밸런스 타임라인 (`Night 01 → 04 → 07 → 14`)
   - `04` HACCP · GMP · 6無 화학부형제 · 잔류농약 320종 불검출 신뢰 인증
3. **실구매자 필터형 포토 리뷰 & FAQ**
   - `전체보기` / `재구매 인증` / `수면·컨디션` / `맛·목넘김` 실시간 탭 필터링, 정렬, 도움돼요 카운트, 포토 라이트박스
   - 핵심 구매 장벽 해소용 5대 FAQ 아코디언
4. **모바일 인앱 브라우저(390px) 퍼널 최적화**
   - 하단 고정 구매 바 → 모바일 옵션 선택 바텀시트 → 실시간 무료배송(50,000원) 금액 게이지 & **1클릭 트라이얼 업셀** 장바구니 드로어 → 주문 완료 데모 모달
5. **스레드(Threads) 촬영용 클린 모드**
   - 기본 상태에서 하단 `TimeSaver Studio 외주 제작 문의` 배너 노출
   - `[스레드 클린모드]` 버튼 클릭(또는 키보드 단축키 `C`) 시 외주 배너 즉시 숨김/복원 지원
