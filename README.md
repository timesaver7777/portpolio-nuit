# NUIT LAB (뉘이랩 공식몰) — 건기식·이너뷰티 고전환 D2C 자사몰 포트폴리오

## 5대 공식몰 멀티 뷰 & 전환 퍼널 아키텍처
1. **공식몰 메인 홈 (`HOME`)**
   - 에디토리얼 브랜드 히어로 캠페인 + 누적 판매·리뷰 지표
   - **공식몰 첫 방문 5,000원 웰컴 쿠폰 즉시 발급** (클릭 시 실제 장바구니 결제액에서 `-5,000원` 자동 차감)
   - 4종 베스트·신제품 진열 그리드 (`상세보기` 및 `장바구니 담기` 즉시 연동)
   - 3대 포뮬러 철학 · 정기구독 멤버십 프리뷰 · 실구매 베스트 포토 리뷰 큐레이션
2. **전제품 카테고리 스토어 (`SHOP`)**
   - 카테고리 탭 필터(`전체` / `나이트 샷·번들` / `허브 릴렉스 앰플` / `트라이얼·선물세트`) 및 정렬(`인기순` / `할인율순` / `낮은 가격순`)
   - 입문자용 포뮬러 비교 가이드 테이블
3. **고전환 상품 상세페이지 (`DETAIL / PDP`)**
   - 상단 브레드크럼 및 4종 상품 빠른 전환 탭
   - 퍼스트 폴드 바이박스: 4종 스튜디오 썸네일 갤러리 + `★ 4.9 (1,428건)` 앵커 + 14시 당일출고 카운트다운 + 번들 라디오 선택기(`1박스 12%↓` / `3박스+4포 BEST 32%↓` / `6박스 45%↓`) + **정기구독 추가 10% 실시간 토글**
   - 4단계 시맨틱 설득 섹션: 리포좀 액상 체내 흡수율(91% vs 24%) 시각화 → 타사 대비 5대 스펙 비교표 → 원료 배합 & 14일 나이트 타임라인 → HACCP/GMP 안전 인증
   - 실구매자 필터형 포토 리뷰(`전체/재구매/수면·컨디션/맛·목넘김`) + FAQ 아코디언
4. **정기구독 전용 혜택관 (`CLUB NUIT`)**
   - 구성별(`1박스` / `3박스` / `6박스`) 정기구독 실시간 절약 금액 계산기 및 원클릭 정기구독 장바구니 담기
5. **브랜드 스토리 (`BRAND STORY`)**
   - 서울 성동구 연무장길 포뮬러 연구소 오리진 스토리 및 원료 원칙 매거진 뷰
6. **모바일 인앱(390px) 최적화 & 스레드 촬영 클린모드**
   - 모바일 상단 1클릭 GNB 바 + 하단 고정 구매 바 + 옵션 바텀시트 + 실시간 무료배송 게이지 & 1클릭 업셀 장바구니 드로어
   - 스레드 녹화/캡처 시 `[스레드 클린모드]` 버튼(단축키 `C`)으로 외주 문의 배너 1클릭 숨김/복원
