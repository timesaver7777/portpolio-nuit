# NUIT LAB (뉘이랩) — 브랜드 공식 홈페이지 & DB 전환형 캠페인 랜딩페이지 포트폴리오

> **TimeSaver Web Studio** 브랜드 홈페이지 & 고전환 랜딩페이지 외주 수주용 레퍼런스 프로젝트 (`https://portpolio-nuit.vercel.app/`)

카페24·아임웹 등 규격화된 쇼핑몰 장바구니 템플릿이 아니라, **신규 브랜드 런칭·사전예약·무료 샘플키트 DB 수집·약국/클리닉 B2B 입점 제휴**를 목적으로 기획·디자인·퍼블리싱된 **맞춤형 브랜드 홈페이지 겸 원페이지 설득 퍼널**입니다.

---

## 핵심 설계 포인트

1. **브랜드 공식 홈페이지 헤더 & 원페이지 설득 아키텍처**
   - 장바구니·배송비 게이지·할인 쿠폰 팝업 등 쇼핑몰 요소를 완전히 배제하고, 브랜드 철학(`Brand Philosophy`) → 인지질 리포좀 생체전달 과학(`91.4% 전달 지수`) → 4종 포뮬러 라인업 브리핑 → 5대 비교표 → 14일 나이트 루틴 → 식약처 HACCP/GMP 4중 안전 기준 → 실사용자·약사 리포트 → 실시간 DB 전환 폼으로 이어지는 논리적 설득 흐름을 구축했습니다.
2. **이중 DB 수집 & B2B 파트너십 전환 폼 (`#conversion-section`)**
   - **개인 고객 탭 (`무료 샘플키트 · 얼리버드 혜택 신청`)**: 성함, 휴대폰 번호 자동 하이픈(`010-XXXX-XXXX`), 수면 고민 칩 선택, 관심 라인업 자동 매핑, 잔여 수량 실시간 차감 및 접수번호 발급 모달 제공.
   - **기업·약국 탭 (`B2B 입점 · 대량납품 문의`)**: 상호/기관명, 담당자, 연락처, 이메일 검증, 제휴 분야 선택 및 공급가 제안서 접수 모달 제공.
3. **자체 제작 하이엔드 스튜디오 화보 9종 수록 (`assets/images/`)**
   - 깨진 외부 링크나 플레이스홀더 없이 Warm Ivory(`#FAF8F5`) · Botanical Charcoal(`#181A18`) · Tart Cherry Burgundy(`#8E2438`) 톤앤매너로 촬영·생성된 전용 비주얼 에셋 9종을 적용했습니다.
4. **390px 모바일 인앱 브라우저 최적화 & 스레드 촬영 클린모드**
   - 스레드·인스타그램 프로필 링크 클릭 시 열리는 `390px` 모바일 뷰포트에서 가로 스크롤(`overflow-x`) 제로 및 하단 고정 듀얼 신청 바(`[B2B 제휴]` / `[무료 샘플키트 · 얼리버드 신청]`)를 지원합니다.
   - 키보드 `C` 단축키 또는 우측 하단 `[촬영 클린모드]` 버튼(`?clean=1` 파라미터 지원)으로 포트폴리오 안내 배너를 즉시 숨기고 깔끔하게 화면 녹화를 진행할 수 있습니다.
